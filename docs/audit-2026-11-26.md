## 3. 问题清单（按优先级）

### P1（下个版本就该修）

**3.1 peer 走廊与宿主线不交（doctor X1 FAIL）**
- 证据：`peerDependencies` 为 `>=0.2.2-0 <0.3.0`，doctor 对 0.2.1-alpha.1 / 0.1.7-rc.2 / 0.0.1-rc.5 三条宿主线均判「不满足」。宿主对不相交的插件是**静默禁用**（能装、不生效、零报错）。
- 风险：一旦用户宿主停在 0.2.1 线（或回退），主题整行被禁，用户以为「装了没效果」。
- 修法：走廊改为 `>=0.1.2-rc.1 <0.2.0 || >=0.2.0-0 <0.3.0`（doctor 给的写法），或在 README 明示「仅支持 0.2.2+」。**取舍**：扩走廊=多测两条线；不扩=写清楚。

**3.2 自定义主题读取静默截断**
- 证据：`src/10-themes.js:174` `.slice(0, CUSTOM_MAX)`；写入侧已判上限，但**读取侧**遇到超过 24 套的存档（旧版本/导入合并）会无声截掉第 25 套，重启即消失，无任何提示。
- 修法：读取时若 `customs.length > CUSTOM_MAX`，保留前 24 并把被截的 id 记进 `pref.droppedCustomIds`，面板顶部给一条可关闭的提示（i18n 成对新增）。

**3.3 无障碍：面板没有标题层级，8 个按钮点击区 < 24px**
- 证据：真机探针 `sectionHeadings: 0`、`minTapTargets: 8`（按钮高度 < 24px，多为 pill 与卡片内按钮）。屏读用户无法按标题跳转；触屏/运动障碍用户易误触。
- 修法：`Section` 的 `.zp-sec-t` 改为 `<h3>`（或 `role="heading" aria-level=3`），`.zp-pill` 最小高度 24px（`min-height:24px`），卡片内按钮 `min-height` 同步。文案门会变 → 跑 `verify:text --update`。

### P2（排进下一批）

**4.1 `!important` 军备竞赛**：512 vs 14。每次宿主给某组件加一条带 `!important` 的规则，插件就得加两条。根因是「宿主把 token 写在 `:root` + 组件内联 var()」；插件用同优先级后写者赢，只能靠 `!important` 抢。
- 方向：把可合并的声明合并（如 230 条 token 的 `!important` 可收敛为按属性前缀分组），并给 `verify:scale` 加一条「`!important` 计数不得高于基线」的棘轮。

**4.2 `ctx.locale` 直访未 inject（doctor K1 WARN）**
- 证据：`src/05-i18n.js:528,553` 用 `ctx.get('locale')`，但主 `inject` 只有 `['slots','theme']`。现在靠 `typeof ctx.get === 'function'` 兜底，不炸，但违反「可选依赖走 get」的意图。
- 修法：确认 `ctx.get` 在当前宿主确实返回服务（doctor X4 判 4 个 inject 名都真实存在，含 locale 服务）；若返回，改成 `ctx.inject(['locale'], cb)` 的可选形态或保持 get 但在 README 的契约表登记。

**4.3 定时器/监听未包 `ctx.effect`（doctor K3 WARN）**
- 证据：`00-core.js:41` window error 监听、`10-themes.js:1028` `hostReapplyTimer`、`20-tokens-and-panel.js:712` `window.__zrSkinT`、`30-quicknav.js:632` `closeTimer`。卸载/HMR 时不回收。
- 修法：把 `window.addEventListener('error')` 与两个 setTimeout 的清理函数挂进 `ctx.effect`；`__zrSkinT` 是模块级，建议收进 apply 闭包并由 dispose 清理。

**4.4 对比度台账无组件级测量**
- 证据：`verify-contrast.mjs` 全部基于 token 对；硬边下划线（60% 品牌色）最低 2.09:1 是我手算的，门禁不守。
- 修法：给台账加「合成色」一组（color-mix 结果），或把下划线改回 100%（回到 ≥3.85:1）。

**4.5 README 门禁表仍写「11 套」**
- 证据：`README.md:247` `verify:contrast` 行写「内置 11 套 × 两态」；实际 12 套。`verify:claims` 没守到这句话。
-「verify:claims」只守数字，不守门禁表里的计数；建议把它扩到 README 的「门禁」小节，或直接改文档。

**4. says 5 面板没有「当前生效主题」的屏读播报**：`aria-live` 只挂在页脚提示上。
- 修法：切主题卡时往 `aria-live` 区域推一条「已切换到 X」；`Pills` 组件用 `role="radiogroup"` + `aria-checked`。

**4. says 6 `isOwnClient` 的同源兜底偏宽**：自定义头是硬门槛，但 Referer/Origin host 比对放行了**任何同源页面脚本**（含其它插件）。对本地单用户场景够用；若将来 web 端暴露到局域网，其它插件页面也能打这两条端点。
- 修法：改为「自定义头 **或** 一次性 nonce」（启动时生成，注入客户端）。
