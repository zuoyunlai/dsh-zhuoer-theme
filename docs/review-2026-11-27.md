## 1. 逐条处置

### P1-1 写回吞掉超限主题 ✅ 已修

- 根因：writePref 用 Object.assign(readPref(), patch) 落盘，而 readPref() 会截断到 CUSTOM_MAX。
- 修法：新增纯函数 zrMergePref(raw, patch, maxCount, specV)（src/10-themes.js），
  合并到**原始存档**；派生字段不落盘；超限段按 id 保留。
- 验收：scripts/test-persist.mjs 13 例（含「存档 30 套、只改一个无关设置 → 仍 30 套」）。

### P1-2 specV 形同虚设 ✅ 已修

- 修法：读取侧读存档真实值；specFromNewer 时不做形状归一；写入取 max(存档值, 当前值)。
- 验收：test-persist.mjs 3 例（补版本号 / 不降级 / 保持不变）。

### P1-3 nonce 落到 Math.random ✅ 已修

- 根因：ESM 里 require 不存在，makeNonce 每次都抛错进兜底；兜底是 Date.now()+Math.random()。
- 修法：import crypto from 'node:crypto'；兜底改 WebCrypto；再兜不住返回空串（服务端会拒绝）。
- 附带：客户端 nonce 过期后永久 403 → 新增 zrIsStaleNonce() + 403 时重领一次。
- 验收：scripts/test-nonce.mjs 6 例；实测 nonce 为 48 位十六进制随机且两次不同。

### P2-1 CSS 注入 ✅ 已修

- 修法：新增 cssUrl() / cssStr()（src/00-core.js），所有拼接点统一走它；
  bgImage 补 data:image/ 前缀校验。
- 验收：scripts/test-css-escape.mjs 15 项（断言安全性质，不比对字面量）。

### P2-2 resize 监听泄漏 ✅ 已修

- 修法：30-quicknav.js 改具名函数，装卸同一对象。

### P3-1 readPref 兜底对象缺字段 ✅ 已修（并入 P1-1）

- 修法：抽出 defaultPref() 单一真源，catch 分支直接返回它。

### P3-2 缓存 key 碰撞与无上限 ✅ 已修

- 修法：FNV-1a hash 作 key；zrCachePut() 统一上限淘汰（12 条）。

### P3-3 report 端点先拼再截 ✅ 已修

- 修法：超限即停、只留 2 KB 头部、标记 truncated。

### P3-4 探针定时器不回收 ✅ 已修

- 修法：新增 zrProbeTimer / zrProbeObserver / zrProbeCleanup 登记表，卸载时统一断开。

### C3「缺 danger 变体」⛔ 撤销

代码里早有一整套：.zp-btn[data-tone="danger"]、.is-armed 两段式确认，三处在用
（恢复克隆值 / 删除自定义主题 / 恢复默认设置）。**这条是我读报告时没先 grep 的错**，
已从待办里撤销——写在这里是为了让下一轮知道「先 grep 再下结论」。

### C5「生成卡只留最新」⛔ 不采纳

预览卡由**宿主**按 tool result 渲染，插件不持有该节点；要「只留最新」只能改宿主会话 DOM，
违背本仓「不劫持宿主结构」的纪律。上游 PTC 能做是因为卡片由它自己画。

## 2. 顺带修好的两处门禁自身缺陷

2. 契约里残留的 _prose 条目是那场假失败留下的残渣（代码早已改用 _markdown_），已删除。
