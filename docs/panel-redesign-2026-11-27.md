# 设置面板 / 配色编辑面板 设计计划

> 日期：2026-11-27｜执行者：Claude Code｜状态：两遍法完成，进入实现
> 依据：`docs/panel-redesign-spec-2026-11-27.md` 与 frontend-design 技能两遍法

## 0. 题目

这不是一个通用后台，也不是一个 SaaS 设置页。它是「卓尔主题」插件的配色控制台：
用户在这里挑选一套现成的配色，或者从一个锚点出发，自己调出一套能直接看见效果的界面配色。
宿主是 DeepSeek Harness 的设置弹层，内容列约 559px；面板必须同时活在 12 套内置主题的
明暗两态里，不能假设自己永远站在暖纸色上。

设计要回答的问题：

1. 12 套主题放在一起时，用户能不能一眼看出「这套是什么气质」，而不是读名字猜？
2. 调 8 个锚点色时，用户能不能同时看见「当前值」「默认值」「这个颜色落在界面哪里」？
3. 面板本身要安静，不能和 12 套主题抢戏；唯一值得记住的东西应该交给配色预览。

## 1. 第一遍：设计计划

### 1.1 色板（4–6 个命名基色）

色板取自插件自己的主题语言（zhuoer 的明暗两套真值），不是另造一套 UI 皮肤。
面板实现时**不写任何色值**，全部经宿主 `--dsw-alias-*` 变量与内联 `--zp-*` 数据变量取值。

| 名称 | 暗态参考 | 亮态参考 | 角色 |
|---|---|---|---|
| 墨（Ink） | `#0E1015` | `#F4F1EC` | 页面底 / 面板底 |
| 面（Surface） | `#17191E` | `#EFECE7` | 侧轨、卡片、试样的第二层 |
| 字（Word） | `#BCBCC0` | `#403C35` | 正文与标题 |
| 朱砂（Vermilion） | `#D13C3C` | `#BD4531` | 品牌 / 选中 / 主按钮 |
| 青玉（Jade） | `#3FB950` | `#2A7C35` | 成功、在线状态 |
| 琥珀（Amber） | `#F59E0B` | `#92400E` | 警告、低对比度提示 |

原则：朱砂只做「当前选择」和品牌锚点，不做大面积装饰；青玉/琥珀只出现在状态点与
对比度读数里；其余全部交给字色层级与 1px 描边。

### 1.2 字体与角色

- **一套字族**：继承宿主界面字体（`font: inherit`），不为面板另设 display 字体。
- 15/600：面板标题；13/600：区块标题；13/400：正文与输入；12/400：行标签、说明、按钮；
  11/400：十六进制色值、比例数字、token 名。
- 等宽只给**真正的数据**（hex、token 名、主题 id 的 title 属性），不给普通小标签。
- 数字用 `tabular-nums`，让 8 个比例的个位对齐；不用全大写、不加字距、不挂箭头。

### 1.3 布局概念

核心结构是**「试样台」**：每套主题不是一张同款圆角卡，而是一块 3:1 的界面试样——
最左一条 3px 品牌色书脊，接着 15px 的表面侧轨，右侧一张内容卡，卡里两行字色线条，
底部三个语义色小点。它同时回答「这套主题的底、面、字、品牌、状态色长什么样」。

对齐：全左对齐；标签列固定 4.8em，控件列可换行；区块之间 18px 留白 + 1px 细线。
窄容器（面板自身 <360px）标签换行到独立一行，不允许横向滚动。

### 1.4 原则

1. **试样优先**：所有「这套主题长什么样」的问题，用界面试样回答，不用更多文字。
2. **一个记忆点**：只让试样成为记忆点；标题、按钮、分组全部退到二线。
3. **双态可见**：锚点行永远同时显示当前色与默认色；改了哪一行，行底与字重给第二重提示。
4. **颜色是数据，不是装饰**：色值只经内联变量进入 CSS；`PANEL_CSS` 保持零色值。
5. **动作词一致**：选中、编辑、保存、撤销、恢复克隆值，同一条流程里不改叫法。
6. **安静的质量底线**：键盘焦点、aria 语义、reduced-motion、窄视口、对比度不靠颜色单独表达。

## 2. 第二遍：对照 brief 的反默认自评

### 2.1 哪些地方是「任何 brief 都能产出的通用默认」

- 「标题 + 说明 + 卡片网格」本身就是设置页默认；第一遍的主题卡仍可能落进 SaaS 卡片套装。
- 主题卡上显示 `zhuoer` / `vintage-paper` 这类内部 id，是系统语言，不是用户语言。
- 头部「圆点 + 当前主题」的胶囊标签，是很典型的模板 chrome。
- 风格预设如果做成一排同样的文字按钮，只是把 12 个词摆出来，没有利用「配色」这个题材。
- 编辑器里「AI 与取色」与锚点并排，会让次要入口抢走锚点的注意力。
- 全局偏好如果继续每块一个 Section，会变成六个同款表单块，层级读起来一样重。

### 2.2 改掉的内容与理由

1. **主题卡改成界面试样，而不是「圆角卡 + 灰条」。**
   试样用该主题自己的底、面、字、品牌、语义色搭一个微型界面：3px 品牌书脊、表面侧轨、
   内容卡、两行字色、三枚状态点。它让 12 套主题在视觉上真的不同，也让「主题」这个词
   落回界面本身。卡外框去掉柔和阴影，只留 1px 细线和选中时的 1px 实线环——不靠阴影分层。

2. **删掉卡片上的内部 id。**
   用户不需要知道 `vintage-paper`；名字已经足够。id 只留在 `title` 属性里供排障。
   这样也去掉了一排等宽小数据标签的模板感。

3. **头部去掉胶囊标签，改成「当前主题 + 该主题品牌色书脊」。**
   书脊取当前主题/强调色的真实值，是一条会随主题变化的细线，不是装饰性 pill。
   「改动即时生效」保留为普通状态行，不再用绿色圆点胶囊。

4. **风格预设改成「配方签」：左侧一条三段色脊（底 / 品牌 / 次色）+ 名称。**
   颜色就是内容，正好说明这套预设是什么气质；点击后生成一套可继续微调的自定义主题，
   并把预设从编辑器里挪到面板的显眼位置。预设不再只是 12 个文字按钮。

5. **编辑器把「AI 与取色」收进可展开的次要区。**
   锚点色是主流程；模型与照片只是「先给一组起点」，默认收起，避免喧宾夺主。
   「高级 token」同样收起。

6. **锚点按 5 个语义带分组：背景与表面 / 文字 / 描边 / 品牌 / 语义色。**
   8 个锚点不再平铺成一列。每行固定显示「当前色 + 默认色」两枚色块，默认色用虚线边，
   当前色用实线边；重置按钮的禁用态保留。

7. **全局偏好收成一条台账，而不是六个同款 Section。**
   一个「全局偏好」大标题，内部用 12px 分组标题 + 细线分隔；控件规格统一，
   不再让「Markdown 精细化」和「配色主题」看起来同样重要。

8. **不引入 display 字体，不加全大写 eyebrow，不用「WORD — fragment」，不挂 →。**
   面板的身份来自试样，不来自字体特效。等宽只服务 hex / token / ratio 这类真数据。

### 2.3 自评结论

计划里的「界面试样」是这个题目自己的东西：它只能出现在一个主题/配色插件里，
换成任何别的设置页都不成立。其余部分（字号、间距、焦点、窄屏）按既有刻度克制成质量底线。
